# Omni — 产品需求文档 (PRD v1.0)

> **一句话定位**：全世界第一个把 **东方命理（八字·五行·易经）** 和 **西方占星（星盘·塔罗）**
> 放进同一个命盘、并且能拿它交朋友的 App。
> **Tagline**: *Two ancient systems. One you.*

---

## 1. 为什么是这个产品

### 1.1 市场缺口

| 竞品 | 强项 | 缺口 |
|------|------|------|
| **Co–Star** | 真实 NASA 星历、极简暴力美学、好友合盘病毒传播 | 纯西方；内容偏冷；变现弱（免费为主） |
| **The Pattern** | 心理学深度报告、"Go Deeper" 订阅 | 纯西方；无东方体系；无实时互动 |
| **Nebula / Sanctuary** | 真人占卜师按分钟计费，ARPU 极高 | 重运营；供给端难扩；无自动化内容 |
| **测测 / 高人** | 东方体系全（八字紫微塔罗）、虚拟币变现成熟 | 只做中文市场；产品观感老旧；不出海 |
| **Chani / Moonly** | 内容质量高、女性向审美 | 单体系；无社交 |

**结论**：北美有 6000 万+ 华裔/亚裔与对东方玄学好奇的 Gen-Z 用户，
但**没有一个 App 把八字和星盘做在一起并做出现代审美**。这就是我们的位置。

### 1.2 目标用户

- **主**：18–34 岁女性，北美，对星座/塔罗已有认知，对"东方神秘学"好奇（Chinese zodiac、风水、易经）
- **次**：北美华裔/亚裔二代，既懂 sun sign 也听过八字，两边都想看
- **场景**：早上通勤看今日运势 → 有事求签（塔罗+卦） → 和朋友/暧昧对象合盘 → 分享到 IG Story

### 1.3 核心差异化（护城河）

1. **真算法，不是随机数**。自研纯 Dart 天文引擎：
   - 太阳/月亮黄经、上升点（真实球面天文计算）
   - **用太阳黄经反解二十四节气** → 八字月柱按真节气换月（这是绝大多数玩具 App 做错的地方）
   - 日柱用儒略日推干支，两个独立历史锚点校验
2. **双系统交叉解读**。同一个出生时刻 → 西方三要素（日/月/升）+ 东方四柱五行，
   AI 把两套语言合成一份人格报告。这是竞品做不到的内容形态。
3. **社交靠"合盘"裂变**，不是靠 feed。合盘必须两个人 → 天然邀请机制。

## 3. 变现设计（现金流）

### 3.1 三层收入

**① 订阅 Omni Plus**（主力，可预测现金流）
| SKU | 价格 | 说明 |
|-----|------|------|
| 月付 | **$7.99/mo** | 3 天免费试用 |
| 年付 | **$39.99/yr** | 折合 $3.33/mo，省 58%，**首年首发价 $29.99** |
| 终身 | $99.99 | 早期回款用，限量放 |

权益：无限 AI 对话、完整命盘+大运流年、无限塔罗/易经、无限合盘、去广告、专属主题。

**② 消耗型玉币 Jade Coins**（冲动消费，提高 ARPU）
| 包 | 价格 | 玉币 |
|----|------|------|
| 小 | $1.99 | 60 |
| 中 | $4.99 | 180（+20%） |
| 大 | $9.99 | 400（+33%） |

消耗点：深度报告 60 币、全年流年报告 120 币、关系全解 100 币、许愿置顶 30 币。

**③ 占卜师市场**（P2，抽成 30%）

### 3.2 定价理由
- Co-Star 免费 → 我们免费层必须够厚才能抢用户
- The Pattern $14.99/mo、Chani $11.99/mo → **$7.99 明显更便宜，是"顺手订"的价位**
- 年付 $39.99 是这个品类的甜点价（Nebula/Moonly 同档）

### 3.3 单位经济
- 一次完整 AI 解读 ≈ 2–4K token（Gemini Flash）≈ **$0.001–0.003**
- 重度用户一个月 150 次调用 ≈ $0.35
- $7.99 订阅毛利率 **>95%**（扣掉 Apple 30%/15% 后仍 >90%）
- 关键指标：D1 留存 >40%、免费→付费转化 **3–5%**、ARPU $0.6–1.2/月

### 3.4 转化漏斗设计
```
装机 → 出生信息 onboarding（不注册，降摩擦）
     → 立刻给"免费完整命盘摘要"（先给价值）
     → 第 2 次打开：合盘/深度报告 处触发 Paywall（价值锚定后再要钱）
     → 3 天试用 → 订阅
```
**原则：Paywall 永远出现在用户已经看到价值之后，绝不在 onboarding 第一屏。**

## 4. 技术架构

```
Flutter (iOS / Android / Web 同一套码)
├── core/engine/        ← 纯 Dart，无 Flutter 依赖，可单元测试
│   ├── astro_math      儒略日 / 太阳黄经 / 月亮黄经 / 恒星时 / 上升点 / 节气求解
│   ├── western_chart   Sun / Moon / Rising / 元素 / 模式
│   ├── bazi            四柱（真节气换月）/ 五行分布 / 生肖 / 纳音 / 十神
│   ├── iching          64 卦 + 三枚铜钱起卦 + 变爻
│   ├── tarot           78 张牌 + 牌阵
│   ├── compatibility   东西合盘综合评分
│   └── daily_fortune   每日运势（同一天同一人结果稳定）
├── core/billing/       订阅 + 玉币 + 权限门禁
└── features/           UI
```

**关键工程决策**
1. 引擎层零 Flutter 依赖 → 可用 `dart test` 直接验证正确性（占卜 App 最怕算错）
2. 运势结果按 (用户ID + 日期) 做**确定性种子** → 同一天反复打开结果一致（不然用户会发现是随机数，信任崩塌）
3. API Key 走 `--dart-define`，**不进仓库**；上线前必须迁到服务端代理

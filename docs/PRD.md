# Omni — 产品需求文档 (PRD v2.0)

> **一句话定位**：唯一一个**把算法摊开给你看**的占星 App。
> **Tagline**: *Astrology that shows its work.*

> **v2.0 修订（定位调整）**：目标用户从「北美 + 华裔」改为**美国本土用户为唯一主要目标**。
> 东方命理从产品核心降级为**可选的第二意见**。理由见 1.2。

---

## 1. 为什么是这个产品

### 1.1 市场缺口

| 竞品 | 强项 | 缺口 |
|------|------|------|
| **Co–Star** | NASA 星历、极简暴力美学、好友合盘裂变、3000 万+ 用户 | 结论从不解释；变现弱（基本免费） |
| **The Pattern** | 心理学深度报告，"Go Deeper" 订阅 $14.99/mo | 内容偏玄，无法验证 |
| **Chani** | 内容质量高、女性向审美、$11.99/mo | 偏内容消费，工具性弱 |
| **Sanctuary / Nebula** | 真人占卜师按分钟计费，ARPU 极高 | 重运营，供给端难扩 |

**它们的共同缺口：没有一个会告诉你结论是怎么来的。**

这不是小事。美国有一大批「对占星好奇但理性」的人——他们会看星座，但也会
翻白眼。现有产品要么要求你全盘相信，要么把内容做成玄学散文。没有人对这批人说：
"这是我们的算法，每一分都能追溯，你自己判断。"

### 1.2 为什么砍掉东方核心

v1.0 的定位是「东西方双系统交叉解读」。放弃它的理由是产品的，不是文化的：

1. **理解成本**。美国本土用户不知道什么是日主、十神、节气。任何需要先教育再使用的
   功能，都会在教育那一步流失掉大部分人。
2. **差异化可以更便宜地拿到**。「摊开算法」这个差异点不需要用户学任何新东西，
   而且直接命中一个现有产品完全没有服务的心理需求。
3. **付费意愿**。美国本土用户 ARPU 更高，而他们要的是把已知的东西做深
   （行星、宫位、行运），不是学一套新体系。

**东方内容不删，降级为可选的「第二意见」。** 引擎已经写好且经过验证，
留着是零边际成本的差异化——对那部分好奇的用户是惊喜，对其余人不构成负担。
规则：**任何东方术语出现的地方，必须同时给出白话解释**（`core/content/glossary.dart` 强制这一点）。

### 1.3 目标用户

- **唯一主要目标**：18–40 岁美国本土用户，女性为主。已经知道自己的太阳星座，
  刷过塔罗，会说「水逆」。**不假设任何东方玄学知识。**
- **场景**：早上看今天天象（月相、水逆、行运）→ 有事抽牌 → 和暧昧对象合盘 → 截图发 IG

### 1.4 差异化（护城河）

1. **摊开算法**。每日分数、合盘分数、流年分数，每一分都能点开看到具名因子。
   竞品里没有一个这么做。这是对「理性但好奇」人群的正面攻击。
2. **真星历**。截断 VSOP87 太阳星历（8 个公开参考时刻误差 < 40 秒）、
   JPL 轨道根数算八大行星（水星最大距角 27.74° 对真值 28°）、真实逆行周期。
3. **诚实降级**。没有出生时间就不给月亮和宫位，落在星座边界会主动提示——
   而不是假装确定。这对目标人群是加分项，不是减分项。
4. **可选的东方第二意见**。想要的人有，不想要的人看不见。

### P2 —— 规模化

| # | 功能 |
|---|------|
| C1 | 真人占卜师市场（抽成 30%，对标 Nebula，ARPU 最高） |
| C2 | 紫微斗数完整命盘 |
| C3 | 中英双语切换 + 中国区版本 |

### 明确不做
- ❌ 完整社交 feed（做不过 IG，且审核成本高）
- ❌ 直播
- ❌ 风水、择日、实景 AR —— 这些对美国本土用户既难理解又难变现
- ❌ Placidus 宫位（暂缓）：它是迭代近似，容易错得很隐蔽而用户无法察觉。
  先上 Whole Sign 和 Equal，两者都是精确的，且 Whole Sign 正是当代美国占星
  正在回归的系统

## 3. 变现设计（现金流）

### 3.1 三层收入

**① 订阅 Omni Plus**（主力，可预测现金流）
| SKU | 价格 | 说明 |
|-----|------|------|
| 月付 | **$7.99/mo** | 3 天免费试用 |
| 年付 | **$39.99/yr** | 折合 $3.33/mo，省 58%，**首年首发价 $29.99** |
| 终身 | $99.99 | 早期回款用，限量放 |

权益：无限 AI 对话、完整命盘+大运流年、无限塔罗/易经、无限合盘、去广告、专属主题。

**② 消耗型玉币 Jade Coins**（冲动消费，提高 ARPU）
| 包 | 价格 | 玉币 |
|----|------|------|
| 小 | $1.99 | 60 |
| 中 | $4.99 | 180（+20%） |
| 大 | $9.99 | 400（+33%） |

消耗点：深度报告 60 币、全年流年报告 120 币、关系全解 100 币、许愿置顶 30 币。

**③ 占卜师市场**（P2，抽成 30%）

### 3.2 定价理由
- Co-Star 免费 → 我们免费层必须够厚才能抢用户
- The Pattern $14.99/mo、Chani $11.99/mo → **$7.99 明显更便宜，是"顺手订"的价位**
- 年付 $39.99 是这个品类的甜点价（Nebula/Moonly 同档）

### 3.3 单位经济
- 一次完整 AI 解读 ≈ 2–4K token（Gemini Flash）≈ **$0.001–0.003**
- 重度用户一个月 150 次调用 ≈ $0.35
- $7.99 订阅毛利率 **>95%**（扣掉 Apple 30%/15% 后仍 >90%）
- 关键指标：D1 留存 >40%、免费→付费转化 **3–5%**、ARPU $0.6–1.2/月

### 3.4 转化漏斗设计
```
装机 → 出生信息 onboarding（不注册，降摩擦）
     → 立刻给"免费完整命盘摘要"（先给价值）
     → 第 2 次打开：合盘/深度报告 处触发 Paywall（价值锚定后再要钱）
     → 3 天试用 → 订阅
```
**原则：Paywall 永远出现在用户已经看到价值之后，绝不在 onboarding 第一屏。**

## 4. 技术架构

```
Flutter (iOS / Android / Web 同一套码)
├── core/engine/        ← 纯 Dart，无 Flutter 依赖，可单元测试
│   ├── astro_math      儒略日 / 太阳黄经 / 月亮黄经 / 恒星时 / 上升点 / 节气求解
│   ├── western_chart   Sun / Moon / Rising / 元素 / 模式
│   ├── bazi            四柱（真节气换月）/ 五行分布 / 生肖 / 纳音 / 十神
│   ├── iching          64 卦 + 三枚铜钱起卦 + 变爻
│   ├── tarot           78 张牌 + 牌阵
│   ├── compatibility   东西合盘综合评分
│   └── daily_fortune   每日运势（同一天同一人结果稳定）
├── core/billing/       订阅 + 玉币 + 权限门禁
└── features/           UI
```

**关键工程决策**
1. 引擎层零 Flutter 依赖 → 可用 `dart test` 直接验证正确性（占卜 App 最怕算错）
2. 运势结果按 (用户ID + 日期) 做**确定性种子** → 同一天反复打开结果一致（不然用户会发现是随机数，信任崩塌）
3. API Key 走 `--dart-define`，**不进仓库**；上线前必须迁到服务端代理
